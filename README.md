# AI Integration in Life Sciences Teaching — GitHub Pages version

Upload the CONTENTS of this folder (not its outer folder) to the root of your `ai-life-sciences` GitHub repository. In Settings → Pages choose Deploy from a branch → main → / (root).

`index.html` is the homepage; `course.html` is the course overview. Ten lesson/exam pages reproduce supplied Squarespace text in their content blocks. Lesson completion is saved locally in the visitor’s browser and is **not** an official registered-user completion record. The exam is a written final task, not an automated grading service.

The contact page uses an email link rather than a non-working form. Review any externally hosted embedded images/videos because Squarespace may restrict or remove them once your subscription ends. The original first-lesson PDF is at `assets/A_Brief_Introduction_To_AI.pdf`.
